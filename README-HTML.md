# JAK Stationary Stock Management System (HTML Version)

A simple, fast, and easy-to-use stock management system built with HTML, Bootstrap CSS, and JavaScript.

## 🚀 How to Run

### Option 1: Direct File Opening
1. **Double-click** on `index.html` to open it in your web browser
2. **That's it!** No server setup required

### Option 2: Using a Local Server (Recommended)
1. **Right-click** on `index.html`
2. Select **"Open with"** → Choose your preferred browser
3. Or drag the file into your browser window

## 🔧 How It Works

### Stock Management
1. **Add products** with initial stock levels
2. **Record sales** → Stock automatically decreases
3. **Adjust stock** → Add/remove items manually
4. **Monitor levels** → Get alerts for low stock

### Sales Process
1. Go to **Sales** page
2. Click **"Record Sale"**
3. Select product and quantity
4. Confirm sale → Stock updates automatically

### Stock Adjustments
1. Go to **Stock Adjustments** page
2. Click **"Adjust Stock"**
3. Choose add/remove and quantity
4. Add reason for adjustment
